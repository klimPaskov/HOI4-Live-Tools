# HOI4 Live Tools — plan

An MCP server that lets an AI agent play Hearts of Iron IV on Windows and macOS: test mod features end to end, and play a meaningful campaign as any country while understanding what is going on.

Requested by the user (5 Oct 2026): "it could be smart to create an mcp server to like play hoi4 for agents. So agents can control hoi4 and test features all autonomously using the mcp." and "the mcp should also allow to like actually play a meaningful campaign and help understand what is going on, etc. ... You could for example play as any country and actually take focuses and play, etc."

## Goals

1. Feature testing: launch, set up a precise game state, trigger content, run time, capture every popup, read log errors and save state, and produce a test report, with no human at the keyboard.
2. Campaign play: an agent plays a nation for years: picks focuses, research, production, construction, laws and advisors, decisions, diplomacy, divisions, fronts and offensives, and reacts to events, through the real game interface (no cheats in campaign mode).
3. Understanding: the agent always knows the situation: a structured state model and a concise briefing (date, wars, fronts, threats, economy, focus and research progress, recent events and news, what needs a decision), plus visual views of the map.
4. General and public: works with any mod or vanilla, any country, documented and bundled by the HOI4 Mod Setup app.

## Non-goals

- Superhuman micro or exploiting game bugs. The agent plays at human speed and with human-visible information unless a tool is explicitly in test mode.
- Multiplayer, Ironman, or modifying the game install.

## Architecture

Python 3.9 stdio MCP server (`python -m hoi4_live`), standard-library protocol plus numpy, Pillow and opencv-python-headless. Dependencies are installed from PyPI. Five layers:

1. Desktop: HOI4 window discovery and focus; capture with ffmpeg `ddagrab` (GDI returns black for HOI4); input with SendInput; Windows.Media.Ocr through a persistent PowerShell WinRT host (text plus boxes); template matching with OpenCV; a cross-process desktop lock.
2. Game control: launch/quit (debug or normal), playset and settings backup/restore, main menu navigation (new game by bookmark and tag, load, continue), console (open, run, verify closed), pause/speed, save.
3. Perception: screen classifier (main menu, loading, map, open panels, popups, console), popup reader (event, news, super-event: title, text, options, picture box), panel readers (top bar resources, political power, stability, war support, factories, manpower, date), tooltip reader (hover then OCR), map views (map mode screenshots of a region, province/state at a screen point).
4. State: two sources.
   - Telemetry companion mod (`hoi4_live_telemetry`, generated by the server into the user mod folder and added to the playset on request): an on_action and scripted effects that, every in-game day (player) and week (world), write compact `HOI4LIVE {json}` lines to game.log using `log` with dynamic variables: political power, stability, war support, factories by type, manpower_k, divisions, current focus and progress, research slots in use, wars and war score, faction, puppets, resources, fuel, equipment deficits where readable, front states, plus the player's flags and variables the agent registers. Cheap, fast and current.
   - Plain-text save parsing for deep queries on demand (countries, states, armies and divisions, equipment, production lines, focus tree progress, research, ideas, decisions, wars, variables and flags), with a streaming parser that handles 100+ MB saves and an index cache.
5. Agency: UI-driven actions with verification (every action re-reads the screen or state to confirm it took effect), a campaign loop helper, a journal, and an auto-answer policy for popups.

## Tool surface (MCP tools; small, composable, documented with examples)

Session and safety: `hoi4_status`, `hoi4_launch`, `hoi4_new_game`, `hoi4_load`, `hoi4_save`, `hoi4_shutdown`, `hoi4_lock`.
Low level: `hoi4_screenshot`, `hoi4_ocr`, `hoi4_click`, `hoi4_key`, `hoi4_type`, `hoi4_scroll`, `hoi4_drag`, `hoi4_hover`.
Test mode: `hoi4_console`, `hoi4_eval_effect`, `hoi4_fire_event`, `hoi4_logs`, `hoi4_save_query`, `hoi4_scenario` (deterministic step list → report).
Time: `hoi4_time` (pause, run, step days, speed) with popup capture; `hoi4_advance` (run until a decision point: popup, focus or research finished, construction or production idle, war declared, unit arrived, or a date).
Understanding: `hoi4_state` (telemetry + save model: country, states, military, economy, diplomacy, with filters), `hoi4_briefing` (one-page situation report, deltas since the last briefing, recommended attention points), `hoi4_map` (map mode + region screenshot, front overview), `hoi4_popups` (list, read, answer by index or text), `hoi4_journal` (append and read the campaign log).
Campaign actions (UI-driven, verified): `hoi4_focus` (list available focuses with names, costs and effects from the tree view and mod files; select one; read progress), `hoi4_research` (slots, available technologies, start), `hoi4_production` (lines, assign factories, add or change equipment), `hoi4_construction` (queue buildings by state and type), `hoi4_politics` (laws, advisors, ideas), `hoi4_decisions` (categories, available decisions, take one), `hoi4_diplomacy` (target country actions: justify, guarantee, faction invite, improve relations, volunteers, lend-lease, peace conference basics), `hoi4_army` (templates, recruit, deploy, armies list, assign generals), `hoi4_orders` (front lines, offensive lines, execute or hold, by armies and target states), `hoi4_navy_air` (basic missions and regions).

## Engineering rules

- Every action verifies its effect (screen re-read or state delta) and returns what changed, or a clear failure with a screenshot.
- Resolution independence: positions relative to the window, template matching and OCR rather than fixed pixels; calibrate per session.
- Speed: cache OCR hosts and templates; keep screenshots small unless asked; a tool call returns in seconds.
- Safety: act only inside the HOI4 window; hold the desktop lock only while acting; back up and restore settings and playsets; never touch the user's normal saves (use a `hoi4live_` prefix); campaign mode refuses console cheats.
- The game on this machine is shared: other agents film and test with it. Release the lock between test runs, never quit or relaunch the game unless the task needs it, and leave it paused on the map.
